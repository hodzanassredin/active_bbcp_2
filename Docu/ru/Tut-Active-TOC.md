# Учебник: несколько дел в одной программе

Учебник для программиста, который пишет на Component Pascal в BlackBox и хочет, чтобы программа
делала несколько дел сразу: обслуживала окно и считала, ждала ответа и не замирала, держала общие
данные в порядке. Он объясняет, зачем нужна каждая вещь и когда её брать. Как вещь устроена во всех
подробностях, рассказывают руководства: `Docu/ru/Tasks.md` (задачи), `Docu/ru/Async.md` (библиотека
`Async`) и сообщение о языке `Docu/ru/Active-CP-Lang.md` (мониторы, `AWAIT`, точки уступки).

Сквозной пример учебника — касса и счета. Есть несколько счетов, деньги переводят с одного на
другой. Правил два: сумма по всем счетам не меняется, и счёт не уходит в минус. Пример растёт от
главы к главе; каждая его версия — модуль `ObxBank0`…`ObxBank6` подсистемы `Obx`, его можно
собрать и запустить, у каждого есть страница в `Obx/Docu/ru/`.

3. [Общие данные и монитор](Tut-Active-3.md) — ожидание посреди перевода, `AWAIT`, тупик.
4. [Транзакции](Tut-Active-4.md) — перевод, который откатывается; `Retry` и `OrElse`.
5. [Сообщения вместо общих данных](Tut-Active-5.md) — кассир и окошко; каналы и ящики.
6. [Выбор](Tut-Active-6.md) — ждать сразу нескольких событий; обещание результата.

Часть II. За пределами одной нити

7. [Тяжёлый счёт и блокирующие вызовы](Tut-Active-7.md) — точка уступки, рабочая нить, процесс.

Приложения

Примеры собирает `tools/build64.sh`; они только для Linux AMD64. Команда каждого примера
запускается в окне BlackBox коммандером или из консоли строкой вида

```sh
echo 'ObxBank1.Do' | tools/run64.sh
```
