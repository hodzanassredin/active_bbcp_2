# DemoMD5

Вычисляет MD5 содержимого файла и выводит 32 шестнадцатеричных символа в журнал.
Алгоритм реализован в модуле самостоятельно: 64 шага преобразования, дополнение
последнего блока и 64-битная длина в битах. Готовые хеширующие модули не используются.

Из корня проекта:

```sh
printf 'DevCompiler.CompileThis DemoMD5\n' | bbcb2-cli
printf 'DemoMD5.Do "/tmp/my file.bin"\n' | bbcb2-cli
```

Команда принимает абсолютный или относительный путь. Внешние двойные кавычки
необязательны; они позволяют сохранить пробелы по краям пути.

Из другого модуля можно передать каталог и имя файла отдельно:

```componentpascal
DemoMD5.Sum("/tmp/", "my file.bin")
```

Память не зависит от размера файла: чтение выполняется блоками по 64 байта.
Ограничение размера определяется API `Files`, использующим `INTEGER` для длины
и позиции (до 2 ГиБ минус 1 байт). Во время вычисления файл не должен изменяться.
Ошибки открытия, чтения и параметров выводятся в журнал.

Проверено сравнением с Python `hashlib.md5`: 21 набор данных, включая пустой файл,
стандартные контрольные строки, миллион символов `a`, двоичные данные и длины
55, 56, 57, 63, 64, 65, 119, 120, 127, 128 и 129 байт. Также проверены относительный
путь, имя с пробелами, отсутствие параметра, отсутствующий файл и незакрытая кавычка.
