# DevChmod__Obsd: установка прав выходного файла

[Исходник](../../Mod/Chmod__Obsd.cp) · [DevLnkBase](LnkBase.md)

Платформенный адаптер для ObsdLibc. Определяет наследника DevLnkBase.ChmodHook; при загрузке создаёт экземпляр и вызывает SetChmodHook. Этим побочным эффектом модуль подключает установку прав для ELF writers.

Метод Chmod добавляет расширение outputType, если оно задано, преобразует Files.Name в UTF-8 и вызывает ObsdLibc.chmod с переданным SET прав. Возвращаемые коды преобразования/системного вызова сохраняются в res_, но текущая реализация не выводит по ним диагностику.

Здесь нет самостоятельной команды без аргументов. Нужно загрузить подходящую ОС реализацию; без hook DevLnkBase.Chmod ничего не делает. Наличие исходника адаптера не означает, что он установлен в текущей сессии.
