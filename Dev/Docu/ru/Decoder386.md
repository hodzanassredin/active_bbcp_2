# DevDecoder386: дизассемблер i386/387

[Исходник](../Mod/Decoder386.cp) · [Browser](Browser.md) · [Эмиттер](CPL486.md)

Модуль декодирует инструкции i386 и x87 для просмотра сгенерированного кода. Он является потребителем кода и reference-информации, а не стадией компиляции.

Decode принимает reader и параметры области декодирования/оформления; основная логика распознавания находится во вложенной DecodeInstruction и обработчиках opcode/адресации. Полную многострочную сигнатуру смотреть в исходнике: это программный интерфейс, не команда без параметров.

DecodeProc строит просмотр отдельной процедуры по имени/адресу, используя информацию загруженного модуля. ShowSrc связывает фрагмент с исходным текстом. DevBrowser.ShowCodeFile и импортёр Code используют декодер для вывода кода и навигации.

Полезный маршрут диагностики: найти оператор в source refs → открыть соответствующие инструкции → сопоставить с CPL.Gen* и входными Item из CPC. До загрузки часть адресов остаётся в виде fixup chains, поэтому числовое поле команды не всегда является окончательным runtime-адресом.

Модуль не является универсальным дизассемблером современных расширений x86. При добавлении новой инструкции в CPL проверить, умеет ли Decoder386 её показывать; отсутствие поддержки просмотра не тождественно ошибке генерации.
