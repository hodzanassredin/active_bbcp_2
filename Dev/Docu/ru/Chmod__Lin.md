# DevChmod__Lin: установка прав выходного файла

[Исходник](../Mod/Chmod__Lin.cp) · [DevLnkBase](LnkBase.md)

Платформенный адаптер для LinLibc. Определяет наследника DevLnkBase.ChmodHook; при загрузке создаёт экземпляр и вызывает SetChmodHook. Этим побочным эффектом модуль подключает установку прав для ELF writers.

Метод Chmod добавляет расширение outputType, если оно задано, преобразует Files.Name в UTF-8 и вызывает LinLibc.chmod с переданным SET прав. Возвращаемые коды преобразования/системного вызова сохраняются в res_, но текущая реализация не выводит по ним диагностику.

Здесь нет самостоятельной команды без аргументов. Нужно загрузить подходящую ОС реализацию; без hook DevLnkBase.Chmod ничего не делает. Наличие исходника адаптера не означает, что он установлен в текущей сессии.
