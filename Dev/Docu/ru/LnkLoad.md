# DevLnkLoad: загрузка OCF для статического связывания

[Исходник](../../Mod/LnkLoad.cp) · [Производитель OCF](CPE.md) · [Общая модель](LnkBase.md)

Читает `.ocf` в записи DevLnkBase, разрешает импорты и переводит встроенные chains исправлений в таблицы секций. Это инструмент сборки, не загрузка модулей в работающую систему.

## Входные точки

ThisMod ищет уже загруженный модуль либо вызывает LoadModule и RegMod. Имена с `$` обозначают DLL через LB.ThisDll. AddModule добавляет корень; MainModule назначает главный; ExportModule/ExportAll и ExportVariable формируют внешние экспорты.

LoadModule читает header, секции data/code, инициализирует fix tables, читает исправления, связывает module descriptors импортов и устанавливает флаги модуля. Формат опирается на конкретные смещения mdf_* в runtime descriptor.

## Проверка интерфейса

SearchName делает бинарный поиск по таблице имён. SearchObj проверяет вид объекта и fingerprint; для типа нечётный opt выбирает приватный отпечаток, opt>1 требует экспортированного имени. Анонимный тип ищется через SearchFprint. Ошибка различает отсутствие имени, неправильный класс, fingerprint и видимость.

ReadFixups читает NewRec/NewArr, локальные chains и use-блок. FixExt вызывает SearchObj и затем FixChain; FixChain разбирает absolute/relative/copy/table и регистрирует исправления в LB.

**Особенность текущего пути:** записи mConst в ReadFixups читаются, но ветка `otag # mConst` не вызывает для них FixExt/SearchObj. Поэтому нельзя утверждать, что этот линкер проверяет каждый записанный fingerprint константы так же, как обычную переменную или процедуру. Для анализа гарантий сравнивать с системным загрузчиком и DevLinker отдельно.

DLL-ветвь SearchObj поддерживает импорт процедуры; тип/переменная из DLL дают отдельные ошибки. Наличие общего object model не делает возможности всех линкеров одинаковыми.

Для изменения OCF одновременно проверять DevCPE.OutCode, таблицы mdf_*, кодировку компактных чисел, знаки links и порядок импорта. Приватные сведения CPT нужны здесь только в уже сериализованном виде; модуль не читает `.osf`.
