# Карта подсистемы Dev

## С чего начать

- [Архитектура компилятора](Compiler-Architecture.md): стадии и поток данных.
- [DevCPT](CPT.md): структуры, области, граф типов, отпечатки и файлы интерфейса.
- [Книга Крелиера и Dev](Compiler-Crelier.md): главы, страницы и отличия реализации.
- [Индекс исходников](Source-Index.md): все модули и экспортируемые процедуры с номерами строк.
- [Руководство пользователя](User-Man.md), [платформенные особенности](Platform-Specific.md), [описание языка](../../Docu/CP-Lang.md).

Новые внутренние справки описывают текущие `.cp`. Существующие пользовательские руководства сохранены; некоторые исторические сведения о платформах и интерфейсах могут отличаться от текущих исходников. Индекс исходников позволяет проверить фактический экспорт.

## Инструменты среды

| Модуль | Назначение |
|---|---|
| [DevCommanders](Commanders.md) | Выполнение команд; `par.text/beg/end` передают текст параметров |

| [DevReferences](References.md) | Переход к исходнику/документации, разрешение алиасов IMPORT |
| [DevSearch](Search.md) | Поиск по исходникам/документации и сравнение текстов |
| [DevRBrowser](RBrowser.md) | Просмотр содержимого репозитория/подсистем |
| [DevSubTool](SubTool.md) | Шаблоны исходников типовых компонентов |
| [DevInspector](Inspector.md) | Свойства controls и связанные процедуры |
| [DevMsgSpy](MsgSpy.md) | Сообщения, поступающие view |
| [DevAlienTool](AlienTool.md) | Диагностика представлений, которые не удалось восстановить |
| [DevLinkChk](LinkChk.md) | Проверка гиперссылок в документах; не линкер программ |

DevDebugCmds и DevRTDebug упоминались в прежней карте, но соответствующих исходников в текущем `Dev/Mod` нет. Их наличие в установленной системе эта карта не предполагает.
