# DevCPL486: операнды, метки и кодирование x86

[Исходник](../../Mod/CPL486.cp) · [Архитектура](Compiler-Architecture.md) · [CPC486](CPC486.md) · [CPE](CPE.md)

Низкий уровень backend. `processor=10` обозначает i386. Модуль переводит конкретные операции над Item в байты и записи исправления адресов, используя буфер CPE.

## Item

Item — короткоживущий дескриптор операнда генератора, не узел AST и не постоянная запись таблицы символов.

| Поле | Назначение |
|---|---|
| mode | Переменная, константа, процедура, регистр, память, стек, условие |
| form | Форма значения CPT |
| offset, index, scale, reg | Компоненты адреса/значения, смысл зависит от mode |
| obj, typ | Объявление и тип для адресации, ссылок и descriptor |
| tmode | Где брать record tag или array descriptor |

Основные дополнительные mode: Ind=14, Abs=15, Stk=16, Cond=17, Reg=18, DInd=19. Например, Ind означает адрес `Reg + offset + index*scale`; Var — адрес относительно frame pointer; VarPar требует загрузить адрес из слота параметра. Для Con наличие obj отличает символический адрес от простого значения. Полная таблица находится сразу после Item в исходнике.

## Метки

`Label` — INTEGER: 0 ещё не назначен, положительное значение — адрес, отрицательное кодирует цепочку ссылок и тип link. `NewLbl=0`, `SetLabel(VAR L)` определяет метку и исправляет накопленные переходы. Нельзя трактовать отрицательную метку как обычный адрес.

GenJump выбирает/кодирует переход и оставляет fixup, если цель ещё не известна. Внешние символические адреса используют объектные links; окончательные адреса появляются при связывании. Типы исправлений (absolute, relative, copy, table и др.) должны согласовываться с CPE и reader объектного файла.

## Инструкции

- MakeReg/MakeConst/AllocConst готовят Item.
- GenMove/GenExtMove/GenLoadAdr, GenPush/GenPop обслуживают перемещение и адресацию.
- GenAdd/Sub/Mul/Div, GenShiftOp/GenBitOp — целочисленные операции.
- GenFLoad/FStore/FDOp/FMOp — x87.
- GenJump/GenCall/GenReturn/GenAssert — управление исполнением.
- GenBlockMove/Store/Comp и GenString* — блоки и строки.
- BegStat/EndStat — границы операторов; Init/Close — состояние прохода и CPE.

Выбор высокоуровневой последовательности и распределение регистров остаются в CPC; CPL обязан правильно закодировать уже выбранную операцию, размер, ModR/M и адресную форму. Для проверки изменений полезен [DevDecoder386](Decoder386.md), но корректная дизассемблировка не заменяет проверку поведения кода.
