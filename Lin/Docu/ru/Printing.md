# Печать в Linux

Печать работает в Linux x32 и x64. При запуске GUI процедура
LinConfig.SetupBefore устанавливает LinPrinters: каталог Printers.Directory и
hook StdDialog.PrintHook. Доступны штатные команды настройки печати и печати
документа из меню BlackBox.

В настройке выбираются бумага, ориентация и поля печатной области. Поля самого
документа и расположение колонтитулов задаются отдельно через «Параметры страницы»
BlackBox. В диалоге печати выбираются принтер, страницы или диапазоны и число
копий, поддерживаемое backend принтера. Выделение доступно, если StdCmds сообщает
о возможности его печати. Отмена диалога не создаёт задания.

Для PDF выберите виртуальный принтер «Печатать в файл», формат PDF и имя файла.
Принтеры CUPS отображаются GTK. BlackBox формирует PDF и передаёт его GtkPrintJob;
командная оболочка и команды lpr не используются. Успешное завершение означает
передачу данных backend, а не подтверждение печати на бумаге. Физический принтер
в автоматических тестах не использовался.

Нужны GTK4 с backend печати, Cairo и PangoCairo; для физических принтеров —
настроенная система CUPS. Настройки сохраняются только в текущем процессе.
Консольная среда не требует подключения печати.

Текст, Unicode и геометрия выводятся векторно. PNG передаются в Cairo в исходном
разрешении с учётом DPI. Разбиение документа на страницы и колонтитулы выполняют
существующие модули Printing и Documents. Непоследовательные диапазоны фильтруются
при генерации PDF, без повторной фильтрации при отправке принтеру.

Программный вывод без диалога:

```componentpascal
	LinPrinters.SetOutputFile("/tmp/document.pdf");
	Printing.PrintView(view, Printing.NewDefaultPar("Документ"));
```

Результат доступен в `Printers.dir.Current().res`. SetOutputFile действует на
следующее задание. PDF сначала создаётся во временном файле рядом с целевым и
заменяет его после успешного завершения. LinPrinters.Abort прерывает активное
формирование, сохраняя прежний файл. Для уже отправленных заданий CUPS следует
использовать системное управление очередью.

Проверка обеих архитектур:

```sh
python3 Lin/Test/check_printing.py
```

Для уже собранных деревьев можно добавить `--skip-build`; для одной архитектуры
— `--arch x32` или `--arch x64`. Нужны дисплей и утилиты Poppler. Тест использует
только виртуальный принтер GTK, без физической печати и без имитации движений
мыши. Проверяются диалоги, PDF, ориентация, Unicode, PNG, копии, отмена задания,
диапазоны страниц и команда StdCmds.Print. PDF и журналы остаются в каталогах
сборки. Обычный исполняемый файл не заменяется тестовым.

В ходе работы исправлен возврат REAL/SHORTREAL из foreign-функций SysV в
DevCPCamd64: результат XMM0 переносится в стек x87, используемый выражениями CP.
Проверки включают прямые и косвенные вызовы и арифметику с их результатами.
